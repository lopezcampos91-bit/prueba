# Fichas de Infantil

Fichas diarias al estilo Kumon para un niño o niña de 3 años (1.º de Educación Infantil), **de lunes a jueves**, unos **10 minutos al día**.

Abre `fichas.html` en el navegador de una tablet o un móvil. No necesita instalación ni internet, salvo para cargar las fuentes.

## Plan semanal

| Día       | Ficha 1 | Ficha 2 | Ficha 3            |
|-----------|---------|---------|--------------------|
| Lunes     | Números | Letras  | Trazos             |
| Martes    | Números | Letras  | Formas y colores   |
| Miércoles | Números | Letras  | Trazos             |
| Jueves    | Números | Letras  | Lógica             |
| Vie–Dom   | Descanso (se puede activar desde la zona de padres) | | |

Cada ficha tiene 5 ejercicios (4 en Trazos). Una voz lee cada pregunta, y el altavoz la repite.

## Niveles

- **Números:** contar hasta 3 → hasta 5 → reconocer del 1 al 5 → contar hasta 10 → reconocer del 1 al 10 → ¿dónde hay más? → sumar hasta 5
- **Letras** (letra de palo): A y E → A, E, I → las cinco vocales → ¿con qué vocal empieza? → M, P, S, L → ¿con qué letra empieza?
- **Trazos** (con el dedo): líneas de lado → hacia abajo → inclinadas → ondas → zigzag → círculos → letras y números
- **Formas y colores:** colores básicos → todos los colores → formas básicas → más formas → forma y color juntos
- **Lógica:** grande y pequeño → ¿cuál es diferente? → series de dos → series de tres

## Cómo se sube de nivel

Como en Kumon, solo se avanza cuando el nivel actual sale fácil: **dos fichas seguidas con un 80 % o más de aciertos a la primera**. Si se equivoca, puede volver a intentarlo, pero ese ejercicio no cuenta como acierto a la primera.

Si tres fichas seguidas salen flojas, la zona de padres recomienda bajar un nivel.

## Zona de padres

Mantén pulsado el botón **Padres** unos 2 segundos. Desde ahí puedes:

- ver el nivel de cada área y los resultados de las últimas fichas
- subir o bajar niveles a mano
- poner el nombre del niño o la niña
- activar o desactivar la voz
- permitir fichas de viernes a domingo
- borrar el progreso

El progreso se guarda en el navegador del dispositivo. Usa siempre el mismo.

## Consejos

- Haz las fichas siempre a la misma hora, por ejemplo después de merendar.
- Siéntate a su lado y elogia el esfuerzo más que el resultado.
- Si está cansado, una sola ficha es suficiente.
- Al terminar las tres fichas del día gana una pegatina para su álbum.
